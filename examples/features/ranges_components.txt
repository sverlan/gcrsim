# Ranges in component numbers: a graph-controlled chain that walks around four components.
#
# In the general [rules] section the numbers of the source and the target component may use ranges. The line
#     {:X}, S -> c{:X} S, {:X%4+1}
# is four rules: in component 1 write c1 and go to component 2, in component 2 write c2 and go to component 3, ... and in
# component 4 write c4 and go back to component 1. Component numbers are not wrapped by themselves: {:X%4+1} does it.
#
# After 8 steps the string is c1 c2 c3 c4 c1 c2 c3 c4 S and the derivation is back in component 1.

[symbols]
alphabet = "S c{:X}"

[symbols.ranges]
X = "1..4"

[axioms]
1 = ["S"]

[rules]
{:X}, S -> c{:X} S, {:X%4+1}; name:walk
